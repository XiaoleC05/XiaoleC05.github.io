## 使用方式（GitHub README）

1. Fork 本仓库到你的 GitHub 账号
2. 点击 README 中的 SVG 路线图，按**从上到下、从左到右**顺序刷题
3. 配合 VS Code LeetCode 插件做题
4. 将完成的题解放入 `user/` 目录，可「点亮」SVG 中的题目（蓝色实验瓶为题解链接）

## LeetCode 路线图模块

GitHub 仓库 README 中列出的 SVG 路线图及进度：

| 模块 | 进度 |
|------|------|
| 树（Tree） | 100% |
| 堆 / 栈 / 队列 | 100% |
| 链表 | 100% |
| 二分查找 | 100% |
| 几何题 | 100% |
| 小众题 | 100% |
| 动态规划 | 约 40% |
| Codeforces Div.2/3 | 进行中 |

路线图 SVG 位于仓库 `images/` 目录，例如：

- `leetcode_tree.svg`
- `leetcode_dp.svg`
- `leetcode_heap_stack_queue.svg`
- `leetcode_linked_list.svg`
- `codeforces.svg`

在 GitHub 上打开 README 即可点击 SVG 跳转刷题。

## 仓库还包含

- **templates/** — KMP、线段树、并查集等算法模板
- **map/** — LeetCode、Codeforces、洛谷等题单映射
- **user/** — 个人题解目录（用于点亮进度）
- **docs/** — Git / VS Code 新手教程、开发文档
